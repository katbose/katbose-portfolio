One version covers the whole project. There are no separate version streams for the web, docs, cms, or dash workspaces, and tags are exactly `vX.Y.Z` with no prefix or suffix.

Entries are written by release automation from [Conventional Commit](https://www.conventionalcommits.org) messages, newest first.

## 0.0.0

Baseline import of the portfolio, recorded before the monorepo restructure. This is not a tagged release.

It is kept here deliberately: release automation locates its insertion point by scanning for the first version heading, and anchoring on this one keeps the page title and the notes above it from being rewritten on every release.
